# CoursePilot 教育业务使用说明

当前教育版服务培训机构的课程咨询和教务办理，使用 Python 后端。作业辅导、知识答疑、考试安排和学习计划是早期角色设计，不再属于当前默认池；类与枚举保留不等于业务仍在默认执行。

## 当前可以体验

- 咨询课程内容和转班政策。
- 按日期、时段、预算和老师条件筛选班级。
- 查询自己的演示报名、剩余课时和差价。
- 核验目标班级是否满足演示免费转班条件。
- 生成草稿、确认提交待审核申请、取消未提交任务和查询申请。

| Agent | 职责 | 业务工具 |
|---|---|---|
| `course_consultation` | 课程和通用政策咨询 | `list_courses` |
| `course_planning` | 候选筛选和比较 | `list_courses`、`get_enrollment`、`check_transfer`、`advise_transfer` |
| `academic_service` | 转班草稿、申请查询与任务推进 | 上述工具及 `prepare_transfer`、`get_application_status`、`assess_free_transfer` |
| `fees_entitlements` | 剩余课时、差价和免费资格 | `get_enrollment`、`check_transfer`、`advise_transfer`、`assess_free_transfer` |

四类角色共享 `search_knowledge_base`；另有 `escalation` 人工交接出口。实际权限来自 `get_tools()`，模型没有 `submit_transfer` 工具。

## 使用方式

按[完整使用指南](完整使用指南.md)启动后端，通过 `/docs` 或 `/chat` 演练，保持相同用户和会话 ID。

推荐发送“转班有什么规定”“帮我转到周日班，不想补钱”“帮我转到 PY-SUN-PM”，随后发送真实返回的确认口令。不要手工编造草稿 ID。

## 数据与迁移

默认演示报名为 `student_demo`，原班周六上午、已付 2000 元、剩余 12 课时。知识库 collection 为 `education_services_v1`，记忆为 `education_episodic` 与 `education_user_profile`。旧 `education_knowledge_base` 不自动迁移到新政策知识库；资料应核验后重新导入。

Skills 当前教务规范入口包括 `skills/course_services/SKILL.md`，按实际角色和关键词匹配；修改后显式调用 `/skills/reload`。

当前为 Python 教务演示后端。`user_id` 由客户端传入，只有 `student_demo` 有预置报名；没有真实登录、审批、支付或退款连接。提交结果为 `pending_review`，不修改报名、不占名额、不扣款。旧客服、作业辅导角色和 Java 描述不属于当前默认业务实现。

更详细的角色与提交边界见[四类 Agent 说明](四类Agent教务版说明.md)。
