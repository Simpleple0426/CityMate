# 真实模型联调与评测

评测入口 `evaluation/live_eval.py`；30 个人工场景定义在 `evaluation/live_cases.py`。
使用 `.env` 中的真实模型配置，产生实际 API 费用。报告不写入 API Key；只使用演示报名资料。

## 两种覆盖范围

- core：真实模型、意图识别、Skills、业务工具、隔离 SQLite，使用脚本提供的对话历史；不包含 Redis、MCP、RAG 和 HTTP。不能用此模式的通过率声称全栈成功。
- full：通过进程内 ASGI HTTP 调用实际 `/chat` 及 API lifespan，连接独立 Redis、真实本地 Chroma 和 MCP 子进程，并调用真实模型。包含工作记忆、历史检索及画像更新；不包含浏览器 UI 操作和真实审批支付。

每个场景使用独立业务数据库，full 模式还为场景生成独立用户和会话，避免跨案例画像污染。
状态数据库与 Chroma 保留在报告的 state_directory，便于审查；不会改写 `data/education.sqlite3`。
为避免 Windows Chroma 文件仍被占用造成清理异常，不在运行中强行删除这些目录。

## 运行

在 CoursePilot 目录，使用已安装 requirements.txt 的 Python 3.12：

```sh
docker compose -p coursepilot-live-eval -f evaluation/docker-compose.eval.yml up -d
python -m evaluation.live_eval --mode core --limit 5 --output data/eval/live-core-smoke.json
python -m evaluation.live_eval --mode full --limit 30 --max-calls 240 --output data/eval/live-full-30.json
```

Redis 仅绑定本机 16379，无持久化数据卷。full 使用本地 Chroma 临时实例，首次使用可能下载 embedding 模型。
API 自动启动 MCP。结束后可停止本次专用服务：

```sh
docker compose -p coursepilot-live-eval -f evaluation/docker-compose.eval.yml down
```

可用 `--repeats 3` 重复运行或 `--no-skills` 做 Skill 对照。对照应保持模型、案例、轮数和其他配置相同；该开关仅关闭 Skill 注入，保留角色系统指令及业务规则。
可用 `--case normal --case change` 只复测指定场景；用 `python -m evaluation.live_report data/eval/live-full-30.json` 生成 Markdown 摘要。
`--max-calls` 限制 SDK 请求次数（含聊天和远端向量请求，不含 SDK 内部重试），`--turn-timeout` 限制每轮等待秒数。
脚本会增量保存报告。status=blocked 表示预检、环境或预算阻塞，不能按完整执行解读。

## 如何读报告

逐轮保存用户消息、实际回复、工具轨迹、要求/草稿/申请快照、检查项、耗时。
确认口令来自真实生成的草稿；没有草稿时不伪造 ID，不继续执行依赖的确认。
汇总报告包含完成案例数、通过数、聊天/向量调用数、服务端返回的 token 用量、每轮耗时 P50/P95。
后台画像请求按创建任务时的案例归属计数；首轮预检单独标记。

这些通过率只衡量声明的程序检查：约束、候选、草稿、申请、工具使用和政策证据。
“无模型调用”案例单列，确定性业务分支成功不等于模型推理成功。
回复是否清晰、是否存在复杂的无依据承诺需要阅读实际回复，未使用 LLM Judge 冒充程序核验。
目前没有统计显著性保证，也没有真实学员流量或生产负载验证。
本组短对话未覆盖长会话摘要压缩的效果。后台画像在退出时最多等待 15 秒，剩余任务会取消；取消和缺失 usage 单列，token 汇总仅包含服务端已返回的用量。
当前依赖组合存在 PostHog 遥测接口兼容告警，检索及业务检查仍可运行；该日志噪声尚未处理。

初次运行发现的问题包括：明确转班请求仍重复询问是否生成草稿、Chroma 多字段 where 格式错误、模板向量逐条请求，以及退出时画像任务仍使用已关闭的 Redis。
对应修复和单元测试保留在代码中，初次报告作为基线保留。旧基线的 token 统计只含聊天请求，新报告同时统计聊天和远端向量请求，二者成本不可直接比较。
